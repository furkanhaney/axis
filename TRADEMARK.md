source code. It does not grant rights to present another product, service, or
release as the official Axis project.

This policy covers **Axis** when used to identify this machine-learning
framework, its logos, and its distinctive project branding. It does not claim
the ordinary word “axis” outside that technical context. The marks are not
represented as registered trademarks unless explicitly stated otherwise.

The Axis project name and branding are maintained by Furkan Haney. The purpose
of this policy is to preserve clear provenance, not to prevent people from
talking about, teaching, extending, or building with the software.

## Uses that do not require permission

You may:

- truthfully refer or link to the official Axis project and releases;
- say that software is built with, based on, or compatible with Axis when that
  statement is accurate;
- use the name in articles, papers, books, tutorials, talks, benchmarks, and
  other commentary about the project;
- redistribute an unmodified official Axis release under its original name,
  provided you identify its source and do not imply separate endorsement; and
- name a community group or resource in a way that clearly identifies it as
  unofficial, such as “Axis users” or “Community guide to Axis.”

These uses must not suggest sponsorship, endorsement, or official status that
does not exist. A compatibility statement should describe the relationship;
it should not use Axis as the primary name or branding of another product.

## Modified versions and forks

The MIT License permits modified versions and forks. Publicly distributed
modified versions should use their own product name and branding when users
could otherwise mistake them for an official Axis release. They may state that
they are based on Axis and link to this repository. Source-control forks kept
for contribution, testing, or personal development may retain the repository
name when their context makes their status clear.

## Uses that require permission

Please obtain written permission before using an Axis project mark:

- as the name or primary branding of another product, hosted service,
  organization, domain, package, or commercial offering;
- in a way that suggests an unofficial release or service is maintained,
  certified, sponsored, or endorsed by the Axis project; or
- on merchandise or promotional material where the mark identifies the source
  of the goods rather than truthfully referring to the project.

Open a GitHub issue describing the proposed use and mark it as a trademark
request. Do not include confidential information in the issue.

Nothing in this policy limits fair use, nominative use, or other uses permitted
by applicable law. Existing written permissions remain valid according to
their terms.
